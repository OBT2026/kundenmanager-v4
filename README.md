# KundenManager V4 – Testprojekt

Die V4 ist als responsive PWA vorbereitet und nutzt dein Supabase-Projekt.

Enthalten:
- Supabase Login
- Kundenakte mit den gewünschten Feldern
- Kategorien und Status
- Suche/Filter
- Aufgaben, Fristen, Erledigung
- Benutzer und feingranulare Rechte
- Kunden-/Aufgabenzuweisung als Datenbankbasis
- Synchronisation über Supabase
- PWA für iPhone/iPad/PC

## Veröffentlichung
Die Dateien auf einen HTTPS-Static-Host laden, z.B. GitHub Pages. Danach auf dem iPhone in Safari öffnen → Teilen → Zum Home-Bildschirm.

Der Publishable Key steht in `app.js`. Niemals einen Service-Role/Secret-Key dort eintragen.
